# تدقيق المشروع (المرحلة صفر، محدَّث)
- **الحالة:** مشروع جديد من الصفر. لا مستودع سابق ولا أسرار مكشوفة لفحصها.
- **المتوفر:** مواصفات V1.0، وثلاثة شعارات وصور PNG إضافية، ولقطات من فيديو مرجعي.
- **قرارات المالك المعتمدة:** Supabase بدل Firebase؛ التحقق بالهاتف (رسالة نصية أو واتساب) مع البريد وجوجل؛ شرط توثيق الهاتف لجمع الأختام والاستبدال؛ مستويات العميل برونزي/فضي/ذهبي تُحسب من العمليات المؤكدة خلال 12 شهرًا.
- **الشعار:** الملفات المتاحة PNG نقطية بخلفية بيضاء أو سوداء وبظلال. لم يصل ملف SVG حتى الآن. مطلوب لاحقًا: SVG أو PNG شفاف.
- **ما لم يتم:** ضبط تسجيل الدخول، تطبيق العميل، لوحتا التاجر والإدارة، دوال الاكتساب والاستبدال (المرحلة الثالثة).

# حالة تنفيذ الواجهات (المرجع: MASTER UI/UX SPEC v1.0)

## المرحلة A: فحص المشروع (نتيجة فعلية)
- **التقنية:** لا يوجد تطبيق واجهات في المستودع. الموجود: هجرات Supabase، واختبارات SQL، وحزمة design-tokens، وملف نصوص عربية. لا React ولا Next ولا Flutter. لم يُنشأ مشروع تطبيق بعد.
- **قاعدة البيانات (wathaq-dev):** 16 جدولًا، كلها RLS مفعّل، وعدد الصفوف صفر عدا الإعدادات والباقات والمستويات. دوال الخادم المتاحة: `join_program` و`my_tier`.
- **المصادقة:** لم يُعدّ أي مزوّد (هاتف/واتساب/جوجل/بريد). لذلك لا تُعرض أزرار دخول على أنها تعمل.
- **الشعار:** صور PNG فقط (`assets/brand`)، بلا SVG ولا خلفية شفافة. المطلوب لاحقًا ملف أصلي.

## ما نُفّذ فعلًا (المرحلة B: نظام التصميم)
| الملف | المحتوى |
|---|---|
| `packages/design-tokens/tokens.json` | لوحة الألوان من المواصفات، وفاتح/داكن، والتدرج الذهبي، والخطوط، والمسافات، ومدد الحركة (120/200/280/250/350/400ms) |
| `packages/design-tokens/build.mjs` | يولّد `tokens.css` و`tokens.ts` ويفشل إن لم يتحقق التباين (40 فحصًا) |
| `packages/ui/components.css` | الأزرار (مع حالة التحميل)، الحقول، البطاقات، الشارات (أيقونة ونص)، مؤشر التقدم، الأختام، بطاقة الولاء، Skeleton، الفراغ والخطأ، Toast، شريط التنقل ذو الأقسام الخمسة |
| `packages/ui/build-showcase.mjs` و`showcase.html` | صفحة مرجعية تعرض كل ما سبق بالوضعين |

الحركة تحترم `prefers-reduced-motion`. حركة الختم الجديد مخصصة للاستخدام بعد تأكيد الخادم فقط.

## فجوات بين المواصفات والمخطط الحالي (لم يُغيَّر المخطط)
- لا جدول للتصنيفات (المواصفات تريدها قابلة للإدارة) · لا جدول إشعارات · لا بلاغات دعم · لا مواقع متاجر · لا حقول شعار وغلاف وساعات عمل في `merchants`.
- المكافآت تملك `is_active` فقط، ولا مسودة/منتهية.
- لا دوال اكتساب أو استبدال أو إصدار رموز (المرحلة 3 من خارطة الأمان).
- لا مزوّد رسائل ولا Edge Functions.

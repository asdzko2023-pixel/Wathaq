# النشر
- **المشروع الحالي:** `wathaq-dev` (eu-central-1)، للتطوير فقط، ولا مشروع إنتاج بعد.
- **التطبيق:** الهجرات بالترتيب بأسماء ذات ختم زمني، ولا تُعدَّل هجرة مطبّقة، بل تُضاف هجرة جديدة.
- **الرجوع:** لا آلية آلية بعد. قبل أي تغيير مدمّر على الإنتاج: نسخة احتياطية مؤكدة وخطة استعادة مكتوبة. الإنتاج يحتاج خطة Supabase مدفوعة لتفعيل النسخ الاحتياطية (يُتحقق من الأسعار الحالية قبل القرار).
- **قبل أي إطلاق:** مشروع إنتاج منفصل، ومفاتيح مستقلة، وفحص `get_advisors` الأمني، وتشغيل الاختبارات.
